## 👨‍💻 About Me

I'm a **Senior Test Engineer with 7+ years of experience** in software quality engineering, specializing in test automation, framework architecture, and end-to-end quality solutions.

I enjoy designing automation frameworks from the ground up, improving existing testing ecosystems, and exploring how AI can make software testing smarter and more efficient.

My work focuses on building reliable, maintainable, and scalable automation solutions that bring together UI testing, API validation, database verification, CI/CD pipelines, and intelligent reporting.

- 🔭 Building and evolving automation frameworks using **Java, Selenium, Playwright, and TestNG**.
- 🎭 Working with **Playwright and TypeScript** for modern browser automation.
- 🤖 Exploring **AI-powered testing, MCP integration, intelligent agents, and automated failure analysis**.
- 🔌 Developing API automation solutions using **REST Assured, Postman, and Newman**.
- 📊 Integrating multiple reporting solutions, including **Allure, ExtentReports, ChainTest, and ELK Stack**.
- ⚙️ Implementing CI/CD automation using **Jenkins, Maven, Git, and Docker**.
- 🗄️ Working with SQL and backend validation to ensure end-to-end data integrity.
- 🧠 Passionate about clean code, modular architecture, reusable components, and continuous improvement.

**My philosophy:** Build automation that is reliable, maintainable, observable, and intelligent.
